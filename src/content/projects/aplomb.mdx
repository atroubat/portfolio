## Le projet

Aplomb est mon application de gestion de budget personnel et de foyer. Elle centralise les revenus, les charges communes ou personnelles, les comptes et l'épargne dans une interface pensée pour faire le point rapidement chaque mois.

## Ce qu'elle permet

- Naviguer par mois et basculer entre une vue **Foyer** et une vue par personne
- Suivre les revenus fixes ou variables et leurs exceptions mensuelles
- Répartir les charges communes entre les membres du foyer
- Gérer les charges fixes, les dépenses personnelles et les transferts
- Suivre plusieurs objectifs d'épargne, avec versements et retraits
- Comparer le budget aux méthodes **50/30/20** et **75/15/10**
- Sauvegarder et restaurer les données au format JSON

## Architecture

- **Frontend** : React, React Router et Recharts
- **Backend** : Fastify avec validation des données partagée via Zod
- **Stockage** : SQLite et migrations versionnées
- **Déploiement** : image Docker auto-hébergée sur mon homelab derrière Traefik

L'application comprend également un mode démonstration totalement isolé, utilisé pour la capture ci-dessus : les personnes, montants et opérations affichés sont fictifs.

## Méthode de développement

Aplomb a été développée en **vibe coding** : les agents IA ont produit et fait évoluer le code à partir de mes demandes. Mon rôle a surtout consisté à définir le besoin, préciser les règles métier, tester le résultat et guider les itérations jusqu'au déploiement sur mon homelab.

## Ce que j'en retiens

Ce projet m'a surtout appris à transformer un besoin personnel en consignes suffisamment précises pour des agents IA, puis à tester, corriger et faire évoluer le résultat jusqu'à obtenir une application réellement utile au quotidien.
