## L'infrastructure

Un petit labo maison installé sur un Mac Mini, que je fais tourner pour le plaisir :

- **Containerisation** : Docker Compose pour les workloads légers
- **Reverse proxy** : Traefik pour exposer les services sur mon réseau privé
- **Monitoring** : une stack Prometheus + Grafana locale pour garder un œil sur tout ça
- **IA locale** : un agent IA exécuté directement sur le homelab pour expérimenter en gardant les données à la maison

## Pourquoi un homelab ?

Pour le plaisir, surtout. Héberger moi-même mes propres services, bidouiller de nouveaux outils, et garder la main sur des cas concrets en dehors du boulot. Rien de tout ça n'est destiné à la production — c'est un terrain de jeu.

## Services hébergés

- **[Aplomb](/projects/aplomb)** : mon application de gestion de budget, avec une API Fastify et une base SQLite persistante
- **[Preuve](/projects/preuve)** : mon coffre de factures, de garanties et de documents de la maison
- **Agent IA local** : un environnement d'expérimentation exécuté directement sur le homelab
- **Observabilité** : Prometheus et Grafana pour surveiller les services et l'infrastructure

Les applications sont déployées avec Docker Compose et exposées uniquement sur mon réseau privé derrière Traefik.
